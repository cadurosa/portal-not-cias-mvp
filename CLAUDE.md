# Projeto: Site estático de notícias

## Objetivo

Criar um site estático de notícias que apresente artigos mockados de forma clara e agradável em diferentes tamanhos de tela.

## Tecnologias e restrições

- Usar somente HTML5, CSS3 e JavaScript puro.
- Não usar frameworks, bibliotecas ou dependências externas.
- Manter os dados mockados em arquivos JSON ou JavaScript locais.
- O site deve funcionar como conteúdo estático, sem necessidade de backend.

## Funcionalidades

- Exibir uma lista de notícias com informações como título, categoria, resumo e conteúdo.
- Permitir filtrar as notícias por categoria.
- Abrir um modal de leitura com o conteúdo completo da notícia selecionada.
- Permitir fechar o modal de forma intuitiva e acessível.

## Layout e acessibilidade

- Criar um layout responsivo para dispositivos móveis, tablets e desktops.
- Usar HTML semântico e controles acessíveis por teclado.
- Garantir contraste adequado e estados visíveis de foco para elementos interativos.
- Implementar o modal com atributos e comportamento apropriados para tecnologias assistivas.

## Diretrizes de implementação

- Preferir recursos nativos da plataforma e manter a implementação simples.
- Separar a estrutura HTML, os estilos CSS, a lógica JavaScript e os dados mockados em arquivos locais quando aplicável.
- Não adicionar ferramentas, frameworks ou dependências externas.
